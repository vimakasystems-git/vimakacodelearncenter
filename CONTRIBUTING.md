# Contributing

1. Open an issue describing a lesson, bug or accessibility improvement.
2. Make a focused branch and keep the application runnable as static files.
3. Verify syntax with `node --check dist/app.js` and `node --check dist/cloud.js`.
4. Check the affected user flow in a browser, including narrow layouts and keyboard use.
5. Explain the change and validation in a pull request.

Use synthetic data in examples. Never commit credentials, student records or personal health data. Attribute sources and retain third-party licenses. Avoid promises of free cloud resources or complete review coverage.

New exercises should describe their input/output contract and explain the limits of their checks. Cloud samples should link to current official documentation.
